InvestScope
Описание проекта

InvestScope — веб-приложение для анализа акций Московской биржи и формирования инвестиционных рекомендаций в зависимости от выбранной стратегии инвестирования.

Проект разработан в рамках курсовой работы по дисциплине «Python в экономических расчётах» и демонстрирует навыки работы с API, базами данных, анализом данных и разработкой веб-приложений на Python.

Основные возможности
- Загрузка исторических данных по акциям Московской биржи через API MOEX ISS
- Хранение и обработка данных в базе SQLite
- Расчёт ключевых инвестиционных показателей:
    - Волатильность
    - Коэффициент Шарпа (Sharpe Ratio)
    - Средняя доходность
- Подбор акций под различные стратегии инвестирования:
    - Консервативная
    - Сбалансированная
    - Высокодоходная
- Построение свечных графиков для выбранных ценных бумаг
- Веб-интерфейс для взаимодействия с системой

Что демонстрирует проект
Проект позволяет продемонстрировать следующие навыки:
- Работа с REST API
- Проектирование и использование реляционных баз данных
- Сбор, хранение и обработка данных
- Анализ финансовых данных
- Разработка веб-приложений на Python
- Визуализация данных
- Работа с библиотекой Pandas

Скриншоты
Здесь можно разместить скриншоты интерфейса приложения.

Режимы анализа
Консервативный
    Подбор акций с наиболее стабильной динамикой цен за рассматриваемый период.
Сбалансированный
    Подбор акций с наиболее выгодным соотношением доходности и риска.
Высокодоходный
    Подбор акций с максимальной исторической доходностью за рассматриваемый период.

Использование
1)На главной странице выбрать тип ценных бумаг.
2)Выбрать режим анализа.
3)Нажать кнопку «Продолжить».
4)Ознакомиться со списком рекомендованных акций.
5)Выбрать интересующую акцию из таблицы.
6)Нажать кнопку «Построить график».
7)Изучить свечной график выбранной акции.

Источник данных
Исторические данные по акциям получаются через API Московской биржи (MOEX ISS).

Используемые показатели
Волатильность - используется для оценки стабильности изменения цены акции.
Коэффициент Шарпа - позволяет оценить соотношение доходности и принимаемого риска.
Средняя доходность - используется для выявления наиболее доходных бумаг за выбранный период.

Запуск проекта
1)Клонировать репозиторий:
    git clone <repository_url>
2)Установить зависимости:
    pip install -r requirements.txt
3)Запустить приложение:
    python app.py
4)Открыть в браузере:
    http://127.0.0.1:5000
